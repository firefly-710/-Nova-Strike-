# 星穹雷霆（Nova Strike）

一款纯前端（原生 HTML / CSS / JS）的弹幕射击 + Roguelike 单机游戏。
无需构建、无需安装依赖，双击 `index.html` 即可运行。

## 玩法概览

- **5 个开局流派**：均衡弹道 / 射速流 / 暴击流 / 无人机召唤流 / 反击流。
- **6 个核心质变**（第 3 波三选一，每局限 1 个，改变打法）：电弧 / 爆裂 / 弹射 / 光束 / 分身 / 超载。
- **8 个难度词缀**（可叠加，最高 3 层），换取更高奖励倍率。
- **天赋树**：4 分支共 175 点，含里程碑效果。
- **图鉴**：敌机 / 首领 / 局内增益 / 核心质变 / 成就 / 兑换码。
- **每日挑战**：固定日期种子（人人同一局），按通关波次评 S/A/B/C 领奖励积分。
- **成就系统**：累计击杀 / 通关 / 核心使用等 10 个成就。
- **无尽深渊**：第 50 波后进入，含检查点与无尽契约。
- 机体涂装（纯外观）、新手教程、连杀与多重击杀反馈、经验光点、BOSS 击破高光等。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD / 鼠标拖拽 / 触摸 | 移动 |
| F | 炸弹（清屏 + 短暂无敌） |
| E | 大招（回血 + 射速提升） |
| Q | 相位冲刺（需局内解锁） |
| P / Esc | 暂停 |
| 1 / 2 / 3 | 直接选择升级 / 残骸 / 契约选项 |

移动端适配：触摸拖拽移动，左下角方向键，右下角技能按钮。

## 运行 / 部署

**本地运行**：直接双击 `index.html`（或浏览器打开它）。

**在线部署**：本游戏是纯静态页面，可托管到任意静态服务：

- GitHub Pages / Netlify / Vercel（免费）
- 阿里云 OSS（开启「静态网站托管」，默认首页设为 `index.html`）或腾讯云 COS

上传以下内容即可：

```
index.html
game.js
style.css
assets/          （图片与精灵图）
```

> `assets/` 下的 `design2.png`、`fighter_design.png`、`sprites_contact_qa.png`
> 是设计参考图，游戏不加载，可删除以减小体积。

## 技术栈

- 原生 HTML / CSS / JavaScript，单文件 IIFE 架构，无构建步骤、无运行时依赖。
- 进度（天赋 / 皮肤 / 成就 / 每日 / 兑换）保存在浏览器 `localStorage`。
