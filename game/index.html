游戏教程

操作方式

  • 移动：方向键 / WASD，或按住鼠标 / 手指拖动战机；移动端可用左下角十字键。
  • 炸弹：F —— 对全场造成范围伤害并清屏，附带短暂无敌（上限 3 枚）。
  • 大招：E —— 能量蓄满后释放，瞬时回复 10% 生命，随后 15 秒每秒回复 1%，并短暂提升射速。
  • 相位冲刺：Q —— 向移动方向突进并短暂无敌（需在局内解锁后出现）。
  • 暂停：P / Esc 或右上角暂停按钮；切换窗口、切后台会自动暂停。
  • 升级选择：数字键 1 / 2 / 3 直接选取当前弹窗的选项。

战斗流程

  • 击落敌机获得经验，攒满经验条升级，每次升级在三个强化中三选一。
  • 每 5 波出现一名 BOSS（首 BOSS 固定装甲要塞，第 10 波起蜂巢母舰 / 相位猎手等随机登场、不重复上一只），击落后可回收一件「BOSS 残骸」强化。
  • 随机「特殊波」会追加陨石带、补给舰队或分裂母舰等事件，并伴随支线目标（完成后有额外奖励）。
  • 战后可随时点右上角「结算」，按当前进度折算奖励积分返回主菜单。

开局流派

  • 均衡弹道：标准射速与伤害，每级基础伤害 +3%，最稳妥的入门选择。
  • 射速流：射速 +35%、伤害 -28%，每发附带目标最大生命百分比伤害，对高血量敌人强力。
  • 暴击流：射速略降，初始 20% 暴击，暴击伤害更高，且每击杀暴击伤害无上限叠加。
  • 无人机召唤流：开局自带浮游炮自动索敌，每击杀无人机火力无上限叠加。
  • 反击流：生命上限更高，受击必中但会把命中你的弹幕反弹给周围敌人，靠挨打输出。

核心质变

  • 第 3 波会出现一次「核心质变」三选一，每局限选 1 个，大幅改变你的打法。
  • 电弧（命中连锁闪电）/ 爆裂（击杀范围爆炸连锁）/ 弹射（子弹弹射多目标）/ 光束（主炮变贯穿激光）/ 分身（镜像复制火力）/ 超载（周期性变身爆发）。
  • 核心质变与流派正交组合：流派定基调 → 核心定形态 → 普通升级与金色模组做加成，每一局都不同。

难度词缀

  • 备战页可叠加词缀，单词缀最高 3 层，层数越高奖励倍率越高；「一键满词缀」可全部拉满。
  • 重装集群（敌机血量↑）、弹幕风暴（敌弹更快更密）、急速突袭（敌机更快）、精英猎场（追加精英）、致命校准（伤害↑）、巨型弹幕（弹体更大）、修复干扰（回血削弱）、能源封锁（大招能量变慢）。
  • 0 天赋 + 0 词缀是最低难度；满天赋 + 满词缀是挑战档，建议熟悉机制后再尝试。

天赋树

  • 用「科技点」在四分支（火力 / 机动能量 / 生存 / 特殊）点亮天赋，每分支点满解锁里程碑效果。
  • 「奖励积分」可用于解锁新机体涂装，或花费 30 积分重置天赋点。
  • 涂装为纯外观，不影响战斗属性。

战斗技巧

  • 画面里 橙黄色的是敌方弹幕（唯一威胁），蓝色的是你的子弹——优先躲橙黄弹，走位优先于站桩输出。
  • BOSS 具有 100% 韧性：减速 / 眩晕 / 卡壳等控制对 BOSS 完全无效，只能靠走位与输出。
  • BOSS 进入狂暴后，每 5 秒会有约 1.8 秒的核心暴露窗口（琥珀色发光），此期间命中伤害 ×1.5，抓住窗口爆发。
  • 血线告急时善用炸弹（清屏无敌）与大招（持续回血）保命，二者充能/冷却独立。

其它玩法

  • 每日挑战：主菜单进入，固定日期种子（人人同一局），按通关波次评 S/A/B/C 领奖励积分，每日一次。
  • 成就：图鉴「成就」分类，累计击杀/通关/核心使用等解锁，给长期目标。
  • 兑换码：图鉴「兑换码」分类输入兑换码兑换奖励，每个兑换码限用一次。

无尽深渊

  • 第 50 波后进入无尽深渊，敌机每波逐步成长（生命与伤害递增），难度持续上升。
  • 无尽中有检查点与「无尽契约」：契约附带增益与代价，按期望取舍；检查点后可选择继续或结算。
